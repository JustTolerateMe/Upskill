# Upskilling: The Master Pillar

An interactive, cyberpunk-themed presentation website built for an office offsite. It presents the case for why **Upskilling** is the Master Pillar that carries the other four workplace pillars: Ownership, Accountability, Business Impact, and Teamwork.

## Features

- **Slide 1: Hero & Intro** - Features a custom anime illustration of Upskilling carrying the other four pillars.
- **Slide 2: Ownership & Accountability** - Breaks down the modern definition of ownership and why refusing to learn represents a business risk. Includes a comparison card graphic of Dinosaur vs Adaptable workflows.
- **Slide 3: Business Impact Multiplier** - Interactive slider that simulates multiplying business impact from 1x to 10x as you add analytics, automation, and AI skills.
- **Slide 4: Teamwork & The AI's Wisdom** - Monospace terminal chat simulation typing out the AI's perspective on career fragility and adaptability.
- **Slide 5: Hulk vs Hulkbuster Showdown** - A retro-synth clicker mini-game complete with web audio synthesizer sound effects, contrasting legacy brute force smashing (results in defeat) vs upskilling/hacking the automation robot (victory).

## Quick Start

### Prerequisites
- Node.js (to run the local server)

### How to Run Locally
1. Clone this repository or open the project folder.
2. Run the dev server using:
   ```bash
   npm run dev
   ```
3. Open your browser and navigate to [http://localhost:3000](http://localhost:3000).

## Controls
- Use **Right Arrow** or **Space** to go to the next slide.
- Use **Left Arrow** to go to the previous slide.
- Use the sidebar dots to jump directly to any slide.
